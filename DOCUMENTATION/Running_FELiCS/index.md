# Running-FELiCS

Welcome to Running-FELiCS!

FELiCS uses four types of files:
* `.json` - configuration files
* `.msh` - mesh files
* `.fel` - data files for input mean flow files and solution files
* `.xdmf` - metadata files referencing the solution files for display in [Paraview](https://www.paraview.org/)

The typical running folder for FELiCS contains the following:
```bash
.
├ config.json
├ boundaries.json
├ mixture.json
├ mesh.msh
├ meanflow.fel
└── output_dir
```
where
* `config.json`, `boundaries.json` and `mixture.json` are the configuration files needed to run.
* The `mesh.msh` file is generated by the user with [Gmsh](https://gmsh.info/) (Be sure to use the `Version 2 ASCII` format!).
* The `meanflow.h5` file contains the mean flow fields required for the set of equations being solved and the coordinates of points where the mean flow is known.
* The output directory `output_dir` must correspond to the `Case{ExportFolder}` field in the `config.json` file.


After running: the solution files and their corresponding Paraview metadata files will be stored in the output directory. Additionnaly, a `log` directory will be created in the output directory, containing the verbose output from the different runs. 

```bash
.
└── output_dir
    ├── solution.h5
    ├── solution.xdmf
    └── log
        ├── felics_06.03.2025-10.44.56.log
        └── felics_06.03.2025-10.45.01.log
```
